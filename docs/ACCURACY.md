# Alarm accuracy report

Generated by `java -jar hibernate-express.jar accuracy` (Java backend, `com.hibernateexpress.sim.AccuracySimulation`). Each row simulates many rides with
Gaussian GPS noise on a real OSRM road route (Hyderabad MGBS → Hanamkonda, 143 km) or a
synthetic edge case, feeding fixes into the same `TripEngine` the server runs for real trips.

**Error = where the alarm actually rang minus where it should ring.** Positive means it rang
early (you get a little extra time), negative means late.

How to read it: with a fix every second the alarm rings within a few tens of metres of the
chosen point. Between fixes the engine keeps counting down at the measured pace, so sparse
GPS (every 5–15 s) costs little. Time-based alarms use the measured pace of the bus, so a bus
that slows down near the stop gets woken up early rather than late.
